# Logos de la veille concurrentielle

Ces fichiers sont conserves localement afin que les logos restent disponibles et nets pendant une presentation, y compris si le site source d'une enseigne est temporairement indisponible.

Sources des fichiers :

- E.Leclerc, Auchan, Lidl, Intermarche, Casino, Monoprix, Systeme U, Mercadona et DIA : versions vectorielles Wikimedia Commons.
- Aldi, Eroski et Pao de Acucar : versions vectorielles WorldVectorLogo.
- Assai Atacadista et Cencosud : sites institutionnels officiels des groupes.
- Franprix : pictogramme vectoriel Simple Icons, conforme a l'identite visuelle de l'enseigne.
- Alcampo et Grupo Mateus : fichiers PNG haute definition issus des ressources publiques des enseignes.

Les marques et logos restent la propriete de leurs titulaires respectifs. Leur affichage sert uniquement a identifier les entreprises dans le cadre de la veille concurrentielle.
